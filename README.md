# ✨ LucidVideo - Pixel Sort Visual Effects

Real-time video effects powered by pixel sort algorithm.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-1.0.0-green.svg)

## 🎯 Features

- **Pixel Sort Effect** - Horizontal pixel sorting based on brightness
- **Hue Shifting** - Psychedelic color cycling
- **Glitch Effects** - Random RGB shifts and artifacts
- **Real-time Processing** - Smooth 60fps on desktop, 30fps on mobile
- **Video Recording** - Export your creations as WebM
- **Multiple Presets** - Psychedelic, Glitch, Subtle, Rainbow
- **Fullscreen Mode** - Immersive viewing experience

## 🚀 Usage

1. Open `index.html` in a modern browser
2. Upload a video file (MP4 or WebM)
3. Adjust effects using sliders:
   - **Intensity** - How far pixels shift
   - **Threshold** - Brightness cutoff for sorting
   - **Speed** - Animation speed
   - **Hue Shift** - Color cycling amount
   - **Glitch** - Random artifact intensity
4. Use presets for quick effect combinations
5. Click **Rec** to record and download your creation
