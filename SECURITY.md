# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please send an email to the repository maintainer. 
All security vulnerabilities will be promptly addressed.

## Security Notes

- This project processes video files locally in the browser
- No data is sent to external servers
- Video files are processed using the Canvas API
- Recording uses the MediaRecorder API which stores data locally
